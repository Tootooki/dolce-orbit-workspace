# Orbit — Dolce Calma workspace

Static GitHub Pages task explorer with browser-side AES-256-GCM decryption.

The task dataset is encrypted in `encrypted-data.json`. The decryption key is **not in this repository**. Open the owner-provided URL containing `#key=…` to unlock it, or paste the access key on the unlock screen. Keep the full link private; anyone holding it can read the dataset.

All task filtering, personal focus selections, notes, and exports run in the browser. No analytics, external fonts, backend, or API credentials. Browser-local notes are not team-synchronized. The register is a saved October 21, 2026 snapshot, not live data.

The public page and its source are public; the encrypted task payload requires the separate access key.
